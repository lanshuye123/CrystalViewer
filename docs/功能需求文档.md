## 一、项目概述

### 1.1 项目背景

晶体学中，空间群描述了晶体内部原子排列的全部对称性，共有230种三维空间群。每种空间群由32种晶体学点群与14种Bravais格子组合，再叠加平移操作导出，决定了晶胞中原子可能占据的等效位置（Wyckoff位置）及其多重度。目前，晶体结构可视化主要依赖VESTA、Diamond等桌面软件，在线工具如Jmol Space Group Symmetry Visualizer提供了空间群对称性的教学可视化，但专注于“输入空间群即展示晶胞结构”的轻量级Web工具仍较为稀缺。

本项目旨在构建一个纯前端的空间群晶胞查看工具，用户只需输入空间群编号或符号，即可自动生成并展示对应的3D晶胞模型，同时以表格形式呈现原子点位信息，降低晶体学学习和研究的门槛。

### 1.2 目标用户

- 材料科学、化学、物理学专业的本科生与研究生
- 从事晶体学研究的高校教师与科研人员
- 对晶体结构感兴趣的自学者

### 1.3 核心价值

- **零依赖**：纯前端实现，无需安装任何软件或后端服务
- **即时反馈**：输入空间群编号或符号即可获得3D可视化结果
- **数据驱动**：原子点位信息以结构化表格呈现，便于查阅和复制


## 二、晶体学知识基线

> 本节为开发团队提供晶体学领域知识参考，确保功能实现符合学科规范。

### 2.1 空间群的基本概念

空间群是晶体结构在三维空间中的全部对称操作的集合，包括点式对称操作（旋转、反映、反演、旋转反演）与非点式对称操作（螺旋旋转、滑移反映）。三维空间群共230种，分属7个晶系（三斜、单斜、正交、四方、三方、六方、立方）。

### 2.2 对称操作的数学表示

空间群中的每个对称操作可表示为Seitz符号 \(\{R|v\}\) ，其中 \(R\) 为旋转部分（3×3矩阵）， \(v\) 为平移部分（3×1列向量）。对原子分数坐标 \((x, y, z)\) 的变换公式为：

\[
\begin{pmatrix} x' \\ y' \\ z' \end{pmatrix} = R \begin{pmatrix} x \\ y \\ z \end{pmatrix} + v
\]

所有对称操作可用坐标三元组（如 \(x, y, z\) ； \(-x, -y, -z\) ； \(-x, y+1/2, -z\) 等）或矩阵-列向量对表示。

### 2.3 Wyckoff位置

Wyckoff位置描述了晶胞中一组由空间群对称操作相互关联的等效原子位置。每个Wyckoff位置具有以下属性：

| 属性 | 说明 |
|------|------|
| Wyckoff字母 | 按对称性从高到低用a, b, c, …标记 |
| 多重度 | 该位置在一个晶胞中产生的等效原子数 |
| 位置对称性 | 该位置保持不变的对称操作子群（Site Symmetry） |
| 代表坐标 | 该Wyckoff位置的一组代表性分数坐标 |

例如，在空间群Pnma中，一般位置的多重度为8，而特殊位置（如位于镜面或二次轴上的位置）的多重度可能为4或2。

### 2.4 原子分数坐标

原子在晶胞中的位置以分数坐标 \((x, y, z)\) 表示，取值范围通常为 \([0, 1)\) 或 \([-0.5, 0.5]\)，分别对应晶胞三个基矢方向的相对位置。分数坐标与笛卡尔坐标之间的转换关系由晶胞参数（\(a, b, c, \alpha, \beta, \gamma\)）决定：

\[
\begin{pmatrix} X \\ Y \\ Z \end{pmatrix} = M \begin{pmatrix} x \\ y \\ z \end{pmatrix}
\]

其中 \(M\) 为晶胞参数决定的变换矩阵。


## 三、数据模型

### 3.1 空间群数据

工具需要内置全部230种空间群的核心数据，数据结构设计如下：

```
SpaceGroupData {
  number: Number          // 空间群编号（1-230）
  symbol_HM: String       // Hermann-Mauguin符号（如 "Pnma"）
  symbol_Hall: String     // Hall符号（如 "-P 2ac 2n"）
  crystalSystem: String   // 晶系名称
  latticeType: String     // Bravais格子类型（P, I, F, A, B, C, R）
  latticeParams: {        // 默认晶胞参数（标准化值）
    a, b, c: Number       // 轴长
    alpha, beta, gamma: Number  // 轴角
  }
  symmetryOperations: [   // 全部对称操作
    {
      seitz: String       // 坐标三元组表示，如 "-x, -y, -z"
      rotation: [[3×3]],  // 旋转矩阵
      translation: [x,y,z] // 平移向量
      type: String        // 操作类型（旋转轴/镜面/螺旋轴/滑移面/反演）
    }
  ]
  wyckoffPositions: [     // 全部Wyckoff位置
    {
      letter: String      // Wyckoff字母
      multiplicity: Number // 多重度
      siteSymmetry: String // 位置对称性
      coordinates: [String] // 代表坐标列表
    }
  ]
}
```

**数据来源**：数据应基于International Tables for Crystallography Vol. A的标准内容整理。对称操作可以以坐标三元组、矩阵形式或几何符号等多种方式呈现。

**数据规模估算**：每种空间群平均包含4-192个对称操作和2-30个Wyckoff位置，全部230种空间群的JSON数据文件预计在2-5 MB。

### 3.2 原子点位数据模型

```
AtomSite {
  label: String           // 原子标签（如 "Na1"）
  element: String         // 元素符号
  wyckoffLetter: String   // 所属Wyckoff位置字母
  multiplicity: Number    // 等效原子数
  siteSymmetry: String    // 位置对称性
  fractionalCoords: [x,y,z] // 分数坐标
  occupancy: Number       // 占据率（默认1.0）
  uIso: Number            // 各向同性温度因子（可选）
}
```


## 四、功能需求

### 4.1 功能模块总览

| 模块编号 | 模块名称 | 优先级 |
|----------|----------|--------|
| F1 | 空间群查询与解析 | P0 |
| F2 | 晶胞3D模型展示 | P0 |
| F3 | 原子点位表格 | P0 |
| F4 | 3D交互操作 | P1 |
| F5 | 显示设置 | P1 |
| F6 | 数据导出 | P2 |

### 4.2 F1：空间群查询与解析

**功能描述**：用户输入空间群标识，系统自动识别并解析为内部数据模型。

**输入方式**：
- 支持空间群编号输入（1-230）
- 支持Hermann-Mauguin符号输入（如 "Pnma"、"Fm-3m"）
- 支持下拉列表选择晶系后筛选空间群

**输入解析逻辑**：
1. 用户输入经过标准化处理：去除多余空格、统一大小写、规范下标表示（螺旋轴应表示为连续数字，如 \(2_1\) 输入为 "21"）。
2. 根据输入匹配内置空间群数据库，返回空间群编号及完整数据。
3. 若输入无法匹配，提示用户并给出建议（如列出相似符号）。

**输出**：空间群基本信息卡片，包含编号、H-M符号、Hall符号、晶系、Bravais格子类型。

### 4.3 F2：晶胞3D模型展示

**功能描述**：基于空间群数据自动生成并渲染晶胞的3D模型。

**晶胞框架绘制**：
- 根据晶胞参数（\(a, b, c, \alpha, \beta, \gamma\)）计算晶胞顶点坐标，绘制晶胞线框。
- 晶胞各轴以不同颜色标识（a轴-红色，b轴-绿色，c轴-蓝色），并在轴端点标注轴符号。

**原子绘制**：
- 默认以球体表示原子，球体半径可按元素类型设定默认值（参考元素共价半径或离子半径）。
- 原子颜色按元素类型区分（可参考CPK配色方案）。
- 原子位置由分数坐标经晶胞参数矩阵变换为笛卡尔坐标确定。
- 支持显示晶胞内全部等效原子位置（由Wyckoff位置+对称操作生成）。

**原子生成算法**：
1. 对每个Wyckoff位置的代表坐标，依次应用空间群的全部对称操作，生成等效原子坐标。
2. 将等效原子坐标归约至晶胞范围内（\([0,1)\) ），去除重复坐标。
3. 为提高可视化效果，可在晶胞边界处生成少量周期性镜像原子。

**默认晶体结构模板**：每种空间群应附带一个默认的“示范结构”。由于仅凭空间群信息无法唯一确定原子种类和坐标，工具需内置一套标准示范数据：可选用该空间群中常见的典型晶体结构（如空间群 \(Fm\bar{3}m\) 对应NaCl型结构），或使用一般Wyckoff位置的虚拟原子。系统默认展示空间群的一般等效位置（General Position）对应的原子排列。

### 4.4 F3：原子点位表格

**功能描述**：以表格形式展示当前空间群中所有Wyckoff位置及原子点位信息。

**表格列定义**：

| 列名 | 说明 | 示例 |
|------|------|------|
| Wyckoff字母 | 位置标记 | a, b, c, d |
| 多重度 | 等效原子数 | 8, 4, 2 |
| 位置对称性 | Site Symmetry | 1, m, 2, -1 |
| 代表坐标 | 分数坐标 | x, y, z |
| 等效坐标列表 | 全部对称等效坐标 | (x,y,z), (-x,-y,-z), … |

**表格交互**：
- 支持按Wyckoff字母排序和按多重度排序。
- 点击某一行时，3D模型中对应的原子高亮显示（改变颜色或添加光环效果）。
- 表格支持展开/收起，展示每个Wyckoff位置的全部等效坐标。
- 支持文本选择与复制。

### 4.5 F4：3D交互操作

**功能描述**：用户对3D晶胞模型进行交互式查看。

| 交互操作 | 实现方式 | 说明 |
|----------|----------|------|
| 旋转 | 鼠标左键拖拽 / 触摸滑动 | 绕模型中心旋转 |
| 缩放 | 鼠标滚轮 / 双指捏合 | 缩放范围0.5x-10x |
| 平移 | 鼠标右键拖拽 / 双指拖动 | 平移视图 |
| 自动旋转 | 开关按钮 | 模型绕Y轴匀速旋转 |
| 重置视角 | 按钮 | 恢复至默认相机位置 |
| 坐标拾取 | 鼠标点击原子 | 显示该原子的分数坐标与元素信息 |

**技术要点**：使用Three.js的OrbitControls实现相机控制。注意Vue3的响应式代理可能干扰Three.js内部对象，需使用`toRaw()`处理Three.js实例。

### 4.6 F5：显示设置

**功能描述**：用户可自定义3D模型的显示参数。

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 晶胞边框 | 显示/隐藏 | 显示 |
| 原子标签 | 显示/隐藏 | 隐藏 |
| 原子半径 | 滑块调节（0.2-1.0倍） | 0.5倍 |
| 模型类型 | 球棍模型 / 空间填充(CPK) / 线框 | 球棍模型 |
| 背景颜色 | 深色 / 浅色 / 自定义 | 深色 |
| 对称元素 | 显示/隐藏螺旋轴、镜面等 | 隐藏 |

### 4.7 F6：数据导出（P2）

- 导出当前晶胞的原子坐标为CIF格式文件。
- 导出3D视图为PNG图片。
- 导出原子点位表格为CSV文件。


## 五、界面设计规范

### 5.1 页面布局

采用左右分栏的响应式布局：

```
┌─────────────────────────────────────────────────────┐
│  顶部工具栏：空间群输入框 | 空间群信息卡片 | 操作按钮  │
├──────────────────────────┬──────────────────────────┤
│                          │                          │
│    3D晶胞视图区域         │    原子点位表格区域       │
│    （Three.js Canvas）    │    （可排序、可交互表格）  │
│                          │                          │
│    ┌──────────────┐      │    ┌──────────────────┐  │
│    │ 显示设置面板   │      │    │ Wyckoff位置表格    │  │
│    │ (可折叠浮层)  │      │    │                  │  │
│    └──────────────┘      │    └──────────────────┘  │
│                          │                          │
├──────────────────────────┴──────────────────────────┤
│  底部状态栏：当前空间群信息 | 原子总数 | FPS显示      │
└─────────────────────────────────────────────────────┘
```

- 桌面端：3D视图与表格左右各占约60%和40%宽度。
- 移动端：上下排列，3D视图在上，表格在下，可折叠。

### 5.2 组件拆分

| 组件名称 | 职责 | Vue3实现方式 |

采用Pinia管理全局状态：

- `currentSpaceGroup`：当前选中的空间群数据
- `currentAtoms`：当前生成的原子列表
- `displaySettings`：显示设置参数
- `selectedWyckoff`：当前选中的Wyckoff位置（用于3D高亮联动）


## 六、技术选型与实现要点

### 6.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 响应式数据驱动 |
| 3D渲染 | Three.js | WebGL三维渲染 |
| 状态管理 | Pinia | 全局状态管理 |
| 构建工具 | Vite | 快速开发与构建 |
| 语言 | TypeScript | 类型安全 |
| UI组件 | 原生CSS / Element Plus（可选） | 界面组件 |

### 6.2 关键技术要点

**Vue3与Three.js的集成**：Vue3的响应式系统通过Proxy包装对象，而Three.js内部使用`Object.defineProperty`定义属性，两者可能产生冲突。解决方案是在传递Three.js对象时使用`toRaw()`剥离响应式代理，仅在Vue数据层维护业务状态，3D渲染层通过`watchEffect`监听状态变化后手动更新场景。

**性能优化**：当晶胞中原子数量较多（如高对称空间群的一般位置多重度可达192）时，应使用`InstancedMesh`进行实例化渲染，将相同几何体和材质的原子合并为单次绘制调用，显著降低GPU开销。目标是保持绘制调用次数低于100次/帧。

**原子绘制方案**：原子用`SphereGeometry` + `MeshPhysicalMaterial`渲染，化学键用`CylinderGeometry`绘制。晶胞边框使用`LineSegments`绘制。

**分数坐标到笛卡尔坐标的转换**：根据晶胞参数构建变换矩阵 \(M\) ：

\[
M = \begin{pmatrix} a & b\cos\gamma & c\cos\beta \\ 0 & b\sin\gamma & c(\cos\alpha - \cos\beta\cos\gamma)/\sin\gamma \\ 0 & 0 & V/(ab\sin\gamma) \end{pmatrix}
\]

其中 \(V\) 为晶胞体积。

### 6.3 数据加载策略

- 将230种空间群数据按晶系拆分为7个JSON文件（或按编号范围分段），使用动态`import()`按需加载。
- 空间群索引表（编号↔符号映射）体积较小，可直接打包进主Bundle。
- 所有数据文件置于`/public/data/`目录下，支持浏览器缓存。
